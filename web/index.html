Planned Surveys → WITSML XML

Misma lógica que la macro del Excel Planned surveys generator (hoja Data, fila 4+). Todo ocurre en tu navegador: no hace falta Azure ni servidor.

Pega desde Excel las columnas B–J (md … dispEw) o edita la tabla.

md (m) incl (deg) azi (deg) tvd (m) mdDelta (m) vertSect (m) dls (deg/30m) dispNs (m) dispEw (m)

Para publicar una URL pública sin Azure: sube la carpeta web a GitHub Pages, Cloudflare Pages o Netlify (gratis). Ver README → «Hosting sin Azure».
